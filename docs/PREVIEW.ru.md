# Автоматическая запись превью

В README показана [анимация WebP без потерь](assets/preview-lossless.webp). Также доступен [GIF](assets/preview.gif). Частота — 50 кадров/с; захват исходного видео — 60 кадров/с.

```powershell
cd C:\path\to\Refined-Quick-Settings-and-Sound
.\tools\present-preview.ps1
```

Скрипт сам открывает панели и выполняет сценарий. Первый ручной проход и mouse-script.json не нужны. Во время записи не трогайте мышь; для остановки удерживайте F9.

## Сценарий

1. Control Center: громкость 20 → 70 → 20.
2. Яркость 100 → 0 → 100.
3. Два нажатия слева от яркости с интервалом около 0,5 секунды; после каждого курсор отходит на 20 физических пикселей вправо и вниз.
4. Sound через кнопку справа от громкости.
5. Раскрытие и закрытие Output device без смены устройства.
6. Раскрытие микшера, System Sounds 50 → 0 → 50.
7. Нажатие правой кнопки строки System Sounds: значение становится 100.

Перетаскивания занимают около 1,3 секунды, переходы курсора — около 0,5 секунды. Переходы между элементами идут по небольшой дуге; перетаскивания прямые. Короткие задержки оставлены для открытия панелей и списков.

## Условия повторения

Сценарий откалиброван на основной экран 2560 × 1440, масштаб 125%, нижнюю панель задач, пять строк микшера с System Sounds первым. Он использует координаты: при другом масштабе, расположении панели задач или количестве строк их нужно скорректировать. Перед записью скрипт выставляет исходные значения и сворачивает микшер. Для яркости требуется DDC/CI.

Запись без звука. MP4, контрольные кадры и журнал сохраняются в tools/demo/local/ и исключены из Git. Итоговый GIF записывается в docs/assets/preview.gif. Мод не собирается и не устанавливается, оболочка не перезапускается.

Альтернативный инструмент для ручной записи произвольного сценария и его повторения — tools/capture-preview.ps1 (Record / Replay / Encode).

## Качество

Исходник записывается без потерь в RGB. Траектория курсора записывается отдельно. Используются оригинальные кадры системного .ani, их hotspots и интервалы — без нарисованной замены. В текущем превью это Rainbow Glow Dark Gray: 72 кадра по 2/60 секунды, цикл 2,4 секунды, родной размер 32 px. GIF использует отдельные локальные палитры для меняющихся областей, 256 цветов на блок и диффузию ошибки; его цветовые ограничения остаются. WebP сохраняет RGB-цвета без потерь и поэтому выбран основным превью в README. Частота движущихся кадров — 50 кадров/с, одинаковые статичные кадры в WebP могут объединяться.

Для повторного запуска нужны FFmpeg, Python 3 и Pillow.

Верх обрезан по максимальной высоте раскрытого Sound: итоговый размер 490 × 885 px, над панелью оставлено 12 px для тени. Начальные 1,5 секунды с подсказкой панели задач исключены; системные настройки подсказок не меняются. Сценарий рендера рассчитан на установленный анимированный .ani-курсор.
