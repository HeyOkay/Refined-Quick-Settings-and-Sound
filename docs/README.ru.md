# Refined Quick Settings and Sound

[English](../README.md)

![Quick Settings and Sound preview](assets/preview-lossless.webp)

Этот «vanilla+» мод для Windhawk перерабатывает панели «Быстрые настройки» и «Микшер громкости» Windows 11 и делает их пригодными для ежедневного использования. Он следует языку дизайна Windows 11, дорабатывая существующие функции и добавляя новые: тонкие ползунки, ровный шаг рядов при любом масштабе экрана и плавный переход рамки к странице «Звук».

Всё работает внутри собственных панелей оболочки (ShellHost): никаких лишних окон. Системный акрил, шрифты, темы, списки, привязки и анимации сохраняются, а изменения оформления откатываются при выгрузке мода.

## Возможности

**Быстрые настройки**

- Управление яркостью для мониторов с поддержкой DDC/CI, с анимированными значками.
- Нажатие на значок яркости включает и выключает ночной свет.
- Параметры дисплея открываются прямо со значка справа от ползунка.

**Звук**

- Страница «Звуковой выход» теперь называется просто «Звук».
- Устройства вывода и ввода и поставщик пространственного звука выбираются из выпадающих списков.
- Ниже — переработанный микшер громкости приложений. Он сворачивается и запоминает последнее состояние.
- Колесо мыши работает на всех ползунках. Нажатие на значок приложения отключает и возвращает его звук, а нажатие на цифру громкости ставит 100.
- Приложения можно скрыть из микшера по имени (настройка мода).

**Панель задач**

- Нажатие на значок громкости сразу открывает «Звук».
- Системный анимированный значок громкости и значок Ethernet для проводной сети.

ID мода: `refined-quick-settings-and-sound`. Версия указана в `mod/sound-native.wh.cpp`.

## Совместимость

Windows 11, x86-64. При разработке мод проверялся на сборке **26300**, преимущественно при масштабе **125%**. Другие сборки и масштабы требуют проверки: мод зависит от внутренних XAML-элементов и символов оболочки, которые могут меняться с обновлениями Windows. Добавленные подписи, включая Sound и Input device, остаются английскими. Для яркости нужен совместимый монитор с включённым DDC/CI.

При первом открытии Sound в каждом процессе ShellHost микшер свёрнут; при последующих открытиях его состояние сохраняется. Отключите другие моды и правила оформления, меняющие те же элементы быстрых настроек, Sound или значка громкости.

**Несовместим с Windows 11 Notification Center Styler и UWPSpy** (и другими инструментами, подключающимися к XAML Diagnostics в ShellHost). Мод находит страницы быстрых настроек и Sound через XAML Diagnostics, а Windows разрешает только одно такое подключение на процесс: кто подключился первым, тот его и держит, остальные подключиться не могут. Мод отпускает подключение, как только страницы найдены, но подключается снова, когда оболочка пересоздаёт панель. Переход на хуки символов ControlCenter.dll возможен в будущих обновлениях.

## Установка из исходника

1. Установите [Windhawk](https://windhawk.net/).
2. Скачайте из репозитория `mod/dist/refined-quick-settings-and-sound.wh.cpp`.
3. В Windhawk создайте новый мод, замените шаблон скачанным исходником, скомпилируйте и включите его.
4. Если панели не обновились, перезапустите ShellHost. Диагностические ошибки доступны в журнале Windhawk.

Готовая DLL не требуется. Быстрые настройки открываются через Win+A, Sound — через Win+Ctrl+V или значок громкости в трее.

## Сборка

Нужны Python 3 и установленный Windhawk (`build.ps1` использует `C:/Program Files/Windhawk/Compiler` и Engine 1.7.3; при другой установке поправьте пути).

```powershell
cd mod
.\build.ps1
Stop-Process -Name ShellHost -Force
```

`build.ps1` сначала запускает `package.py`, который собирает `mod/dist/refined-quick-settings-and-sound.wh.cpp` — единый файл для редактора Windhawk. Правьте исходники в `mod/`, а не `dist`. Тесты интерфейсов свойств: `mod/test-model.ps1` (они не проверяют интерфейс оболочки). Замер скорости открытия панелей: `tools/measure-panel-open.ps1`.
