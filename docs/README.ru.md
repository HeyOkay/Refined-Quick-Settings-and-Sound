# Refined Quick Settings and Sound

[English](../README.md)

![Тёмная тема](assets/preview-lossless.webp?v=01bbd42)

![Светлая тема](assets/preview-light-lossless.webp)

Этот «vanilla+» мод для Windhawk перерабатывает панели «Быстрые настройки» и «Микшер громкости» Windows 11 и делает их пригодными для ежедневного использования. Он сохраняет стиль Windows 11, добавляя тонкие ползунки, равные отступы между строками и плавный переход к странице «Звук».

Мод работает внутри панелей оболочки (ShellHost). Системный акрил, шрифты, темы, списки, привязки и анимации сохраняются, а при выгрузке мода восстанавливается исходное оформление.

## Возможности

**Быстрые настройки**

- В разделе «Внешний вид» можно независимо выбрать обычную форму или капсулы (pills) для плиток быстрых настроек и закрытых полей выбора в Sound.
- В разделе «Дополнительные переходы» можно выбрать до пяти кнопок справа от «Настроек», в том числе «Уведомления», «Графика», «Сетевые параметры», «Питание» и «Центр обновления». Пустые позиции и повторы пропускаются. Если в строке яркости уже есть кнопка параметров дисплея, она не дублируется.
- В строке яркости родной ползунок Windows или ползунок DDC/CI расположен между кнопками «Ночной свет» и параметров дисплея. Ночной свет использует штатную плитку; если она недоступна, открывается его страница в параметрах Windows.
- «Яркость дисплея» по умолчанию работает в режиме «Авто». Используется штатный ползунок Windows, а при его отсутствии добавляется ползунок для мониторов с рабочим диапазоном DDC/CI. В режиме «Отключить» строка яркости скрывается.
- В настройке «Строки плиток» можно выбрать от одной до четырех строк. Число страниц зависит от количества плиток. Для изменения числа строк нужна версия ControlCenter из сборки Windows 26300.9974.

**Звук**

- Страница «Звуковой выход» теперь называется просто «Звук».
- Устройства вывода и ввода и поставщик пространственного звука выбираются из выпадающих списков.
- Ниже расположен переработанный микшер громкости приложений. При первом открытии панели «Звук» в каждом процессе ShellHost микшер свернут. При последующих открытиях он запоминает свое состояние.
- При перетаскивании ползунка и прокрутке колесиком появляется подсказка с новой громкостью. Шаг прокрутки по умолчанию — 2 процентных пункта.
- Нажатие на значок приложения отключает и возвращает его звук. Нажатие на число устанавливает громкость на 100 %.
- В разделе «Скрыть в микшере громкости» можно указать названия приложений или имена исполняемых файлов, по одному на строку. Звук скрытых приложений сохраняется.

**Панель задач**

- «Быстрый доступ к настройкам звука» открывает панель «Звук» по нажатию на значок громкости на панели задач.
- «Выключение звука средним кликом» сохраняет заданную громкость. По умолчанию выключено.
- «Дополнительные параметры звука» в меню значка открывают классическое окно «Звук» из панели управления.
- «Диспетчер устройств» доступен в меню значков сети и батареи.
- В разделе «Альтернативные иконки» доступны в том числе анимированный значок громкости и значок проводной сети из оригинального мода. У каждой позиции свой переключатель. Если его выключить, там появится иконка Windows.

## Совместимость

Windows 11 24H2 и новее (быстрые настройки в ShellHost), x86-64 (на ARM64 не проверялся). При разработке мод проверялся на сборке **26300**, преимущественно при масштабе **125%**. Другие сборки и масштабы требуют проверки: мод зависит от внутренних XAML-элементов и символов оболочки, которые могут меняться с обновлениями Windows. Добавленные подписи доступны на английском, русском, испанском, немецком, португальском (Бразилия) и упрощенном китайском. Для яркости нужен совместимый монитор с включённым DDC/CI.

Отключите другие моды и правила оформления, меняющие те же элементы быстрых настроек, Sound или значка громкости.

Обнаружение панелей использует хуки COM-интерфейсов ControlCenter.dll и публичное дерево XAML; подключение XAML Diagnostics не создаётся. Совместимость с модами, меняющими те же элементы, требует живой проверки. Если панель была открыта при включении мода, закройте и откройте её; при необходимости перезапустите ShellHost.

## Установка из исходника

1. Установите [Windhawk](https://windhawk.net/).
2. Скачайте [единый исходник мода](../mod/dist/refined-quick-settings-and-sound.wh.cpp).
3. В Windhawk создайте новый мод, замените шаблон скачанным исходником, скомпилируйте и включите его.
4. Если панели не обновились, перезапустите ShellHost. Диагностические ошибки доступны в журнале Windhawk.

Готовая DLL не требуется. «Быстрые настройки» открываются через Win+A, «Звук» — через Win+Ctrl+V. Если включен «Быстрый доступ к настройкам звука», значок громкости на панели задач также открывает «Звук».

## Сборка

Нужны Python 3 и установленный Windhawk (`build.ps1` использует `C:/Program Files/Windhawk/Compiler` и Engine 1.7.3; при другой установке поправьте пути).

```powershell
cd mod
.\build.ps1
.\test-model.ps1
```

`build.ps1` сначала запускает `package.py`, который собирает `mod/dist/refined-quick-settings-and-sound.wh.cpp` — единый файл для редактора Windhawk. Правьте исходники в `mod/`, а не `dist`. `mod/test-model.ps1` проверяет логику модели и интерфейсы свойств. Замер скорости открытия панелей: `tools/measure-panel-open.ps1`.
